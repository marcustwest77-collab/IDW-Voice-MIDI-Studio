# V6.3 — connection check and Audio Lab launcher

Open Setup / Help to see live audio processing, microphone level, generated MIDI
since opening the panel and whether IDW sound is enabled. Choose your intended
route for setup instructions. Route selection itself changes no processor settings
and does not select or inspect an actual DAW port.

Enable IDW instrument turns on the synth, stops existing notes, and disables
microphone monitoring and the simple preview. Mute IDW sounds / use DAW stops
notes and turns off all three internal sound paths. These explicit actions update
your current processor settings; they are not temporary overrides.

Send test note requests MIDI note 60 on channel 1. With audio stopped it is disabled.
I heard this test note is a manual confirmation, enabled only after requesting a
test. Generated MIDI alone never checks it. Another test, route change, audio stop
or reopening setup clears it. It is not saved. An external DAW/device change cannot
be detected, so run the check again after changing routing.

Copy setup report now identifies V6.3, includes synth/capture settings, intended
route and manual sound confirmation. It contains signal measurements and settings,
not microphone recordings or cloud keys. Full manual opens the existing manual.

Audio Lab opens the bundled Windows companion from the native standalone's
portable folder. In a DAW, or if the companion was moved, a file picker asks you to
locate Audio-Lab/IDW-Audio-Lab.exe. The chosen path is remembered on this PC. Keep
its entire folder intact. Missing paths prompt again. A successful OS launch request
does not guarantee that the companion finished starting.

The existing Windows tests now check confirmation cannot be inferred from MIDI,
route/audio-stop resets, opening the editor leaves parameters unchanged, and the
connection panel fits the minimum editor size. Actual DAW receipt, microphone
performance and audible output still require testing on your PC.

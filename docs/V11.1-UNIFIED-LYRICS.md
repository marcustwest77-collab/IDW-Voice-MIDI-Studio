# V11.1 — lyrics inside Song Studio

This local source candidate brings writing into the native Song Studio panel. A song now stores its title and lyrics together with its beat and recorded take. Windows/macOS installers for this change have not yet been built or validated.

## Use it

1. Launch the built IDW standalone application and open **Song Studio > Lyrics**.
2. Enter a song title and write or paste your lyrics. Intro, Verse, Hook, Bridge and Outro insert section headings at the cursor.
3. To bring in existing dictation, export a UTF-8 TXT draft from Audio Lab and choose **Import TXT**. Import appends to the current lyrics; it does not replace them.
4. Switch to **Beat controls** to arrange the drum pattern. Return to Lyrics to read or edit while playing or recording.
5. Stop transport and choose **Save song**. The `.idwsong` contains the title, lyrics, beat and take. You can save a lyrics-only draft before recording anything.
6. **Open song** restores all these parts. Save the current project before opening another.
7. **Export TXT** exports the lyric body, including section headings; the separate title field is not included. **Export mix WAV** still exports audio only.

Limits: title 256 characters, lyrics 32,768 characters. Invalid UTF-8 and oversized imports are rejected, preserving existing text. Use the editor's normal keyboard undo/redo while editing.

## Compatibility and current limits

V11.1 reads original V11 song files (format 1), which open with empty title/lyrics. Saving writes format 2. Older V11 applications cannot open format 2: save an upgraded copy under a new name if you need to keep the original usable in V11.

Saving is explicit. Songs and lyrics are not included in DAW state or plugin presets, and there is no autosave or crash recovery yet. Dictation still runs in the separate Audio Lab companion; this milestone does not provide shared-microphone capture or native speech recognition. The existing one-track recording and 180-second limit remain.

For AudioBox USB 96 recording and Pro Tools workflow, follow [the Song Studio guide](V11-SONG-STUDIO.md) and [Pro Tools setup](PRO_TOOLS_SETUP.md). This version does not add an AAX plugin.

## Build and test

On Windows, install Visual Studio 2022 with Desktop development with C++, CMake 3.22 or later and Git. From the repository in a developer terminal:

```powershell
cmake -S . -B build-v11.1 -G "Visual Studio 17 2022" -A x64 -DBUILD_TESTING=ON
cmake --build build-v11.1 --config Release --parallel
ctest --test-dir build-v11.1 -C Release --output-on-failure
```

Configuration fetches JUCE 9.0.2; an offline checkout can be supplied with `-DIDW_JUCE_PATH=...`. Launch `build-v11.1/IDWVoiceMIDIStudio_artefacts/Release/Standalone/IDW Voice MIDI Studio.exe`. Audio Lab packaging is handled separately by the existing build workflow.

The local JUCE-linked Song Studio regression executable passes recording/playback, WAV export, Unicode metadata round trip, editing during playback, original-format migration, invalid/truncated-file preservation, title limits and lyrics-only projects. Editor/processor syntax is checked against JUCE headers. These checks do not establish Windows installation, physical microphone performance or visual correctness.

Before release, check both panel views at minimum size and across skins; import/export text; save/reopen Unicode lyrics and a vocal take; cancel dialogs; test an unwritable destination; and record with the AudioBox while editing. Full platform builds and plugin validation remain required for this candidate.

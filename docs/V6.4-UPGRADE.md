# V6.4 — MIDI take editor

Open Audio Lab from the native app or Run-Audio-Lab.cmd. After transcribing a WAV,
click Review latest MIDI. Alternatively select MIDI take editor > Open MIDI and
choose a recorded/exported .mid file. All editing is local and silent; audition
exports in a DAW instrument track.

## Edit a take

- Click a piano-roll note. Set MIDI pitch (0–127), velocity (1–127), start beats
  and length beats, then Apply note. Beat 0 is the beginning; a beat is one
  quarter note. Tempo changes remain in the file.
- Delete note removes the selected note. Undo and Redo retain up to 20 edits.
  Reset to original is also undoable. Opening another file replaces this history.
- Choose All tracks or a single track. Transpose semitones acts on that scope and
  skips channel-10 drums. Direct note edits can deliberately change drum pitches.
- Snap starts rounds note starts to the selected 1/4, 1/8, 1/16 or 1/32 note grid.
  It preserves each note's length and includes drums in the selected track scope.
  Invalid or overlapping same-pitch/channel edits are rejected without partial
  changes. Transpose never silently clips notes outside the MIDI range.
- Scroll horizontally/vertically and use Zoom + / Zoom - for longer takes.
- Export copy writes a NEW MIDI file. Existing files, including the original take,
  are never overwritten. Unsaved changes prompt before closing or opening another
  take. The editor does not auto-save its in-memory changes.

## What is preserved

MIDI type (0/1), tick resolution, tracks, channels, program changes, controller
values, pitch-bend events, tempo changes and metadata are retained. Automation
stays at its original tick positions when notes move; it does not follow a note.
At a moved repeated-note boundary, note-off precedes the next note-on to prevent
an immediately cancelled/stuck note. Import your exported MIDI into a DAW and
check expression when editing takes with bends, sustain or MPE.

The editor supports up to 4 MiB, 128 tracks, 100,000 events and 20,000 notes.
Type-2 files, SMPTE timing, unterminated/zero-length notes and overlapping repeated
pitches on the same track/channel require a DAW for repair. Files failing import
leave the currently open take intact. This editor does not change WAV audio,
voice cloning models or live pitch detection, and does not provide MIDI playback.

## Validation

Seven new local edit tests cover drum-safe transpose, track scope, range rejection,
note edit/undo/redo, history limits, snap duration preservation and invalid edits.
The Windows packaged-app gate loads and edits real MIDI fixtures, reopens exports,
checks tempo/controller/bend/channel preservation, deletion, boundary ordering and
no-overwrite behavior. A real Basic Pitch output is also opened and exported through
the editor. The GUI gate draws the piano roll and checks editor control bounds at
800-pixel window width. A screenshot of the running editor is included in Previews.

Native processing and VST3 validation gates remain unchanged. No physical microphone,
DAW listening session or cloud account roundtrip is performed by these tests.

# V10.7 Custom Skin Designer — local candidate

This extends V10.6's six built-in themes with five custom colour overrides and a reusable local skin collection. The DSP and MIDI paths are unchanged.

## Use

1. Open **Design skin** beneath the application title.
2. Enter six hexadecimal RGB digits for Background, Panels, Accent, Text and Signal. For example, `#0B0E14` is the original dark background and `#EAC36C` is IDW Gold.
3. Choose **Apply colours** to preview all five changes together. Invalid input leaves the current theme unchanged.
4. Enter a name and choose **Save new skin**. Each save creates a separate file, including repeated names. Choose an entry and **Load skin** to reuse it.
5. Choose **Built-in skin** to disable overrides. This recovery button remains white on black even with unreadable custom colours.
6. Choose **Done** to return to the main interface.

The selected built-in palette supplies button, grid, danger and safety colours. The five overrides are stored with the DAW/standalone state. The skin collection is stored beneath the operating system's user application-data directory in `IDW Voice MIDI Studio/Skins`. A project retains its colours even if the saved skin file is absent. Older projects default to custom overrides off. Presets may also recall/reset appearance as part of their full state.

Audio Lab is a separate application and does not inherit these colours. This candidate uses hex text fields, not a visual colour wheel; contrast is user-selected rather than automatically enforced.

## Build and test

Use the existing repository CMake build instructions. The new `IDWCustomSkins` CTest target covers colour parsing and mapping. Processor regressions cover custom-colour state round trips and migration from older projects.

Locally verified: the new independent C++ custom-skin test and the existing built-in palette test; C++ syntax checking of the editor, processor and processor tests against the local JUCE headers. A linked application build, execution of processor regressions, file-save/load UI checks and a visual pass are still required. There is no V10.7 installer yet.

Manual acceptance checks after a full build:

- Open Design skin from both main views at the minimum window size; inspect all controls.
- Apply different colours and inspect Performance, Studio, Vocal FX, Instrument and Setup panels.
- Enter invalid hex in one field; verify no colours change.
- Set text and background to the same value; recover using Built-in skin.
- Save two skins, including identical names, then load each from another instance.
- Save/reopen a DAW session and standalone state; verify all five colours and override enablement return.
- Load a V10.6 project while overrides are on; confirm they turn off.
- Test a malformed saved XML file and an unwritable skin directory; verify a visible error and unchanged existing files.
- Play continuous audio/MIDI while applying themes; confirm uninterrupted output.

# V6.6 — spoken songwriting controls

Extract the whole package into a new folder. Run Run-Audio-Lab.cmd and open
Lyrics / talk to text. The main voice-to-MIDI program is Run-IDW.cmd.

## Spoken commands (optional, off by default)

Before starting dictation, check Voice commands. Speak a lyric phrase, pause until
it appears, then speak one complete command and pause again. These commands only
apply when the entire recognized phrase matches; 'hello comma world' stays literal.

- comma, period (or full stop), question mark, exclamation mark, colon, semicolon
  attach punctuation to the last lyric line. Empty drafts and section headings
  are not punctuated.
- new line ends the current line; new paragraph leaves a blank line.
- section intro, section verse, section hook, section bridge, section outro
  insert bracketed headings at the end of the draft.

Command help lists the phrases in the app. Turn Voice commands off to dictate those
words literally. Commands never launch programs, delete songs or operate a DAW.
Recognition mistakes are possible: check the appended text and use Undo/Redo.
Command and phrase-layout controls are locked while dictating so queued phrases
are interpreted consistently. Stop before changing them.

## Phrase layout and editing

New line per phrase is on by default. Uncheck it before starting to join recognized
phrases with spaces. Explicit new line/paragraph commands still work in that mode.
New dictation appends to the end; it does not replace a selection or follow the caret.
If typed text ends without a separator, IDW inserts a newline or space before the
next dictated phrase. Each finalized phrase/command is one undoable edit. Redo is
now available next to Undo. Undo history is in-memory and is reset when another
song is opened; use History for previously saved drafts.

The live counter reports Unicode words, nonempty lyric lines and bracketed section
headings. Headings do not count as lyric words or lines. Apostrophes inside words
stay together; hyphenated words are counted separately. Counts are writing aids,
not a syllable, rhythm or rap-flow analysis.

## Preserved features and compatibility

Input 1/2 selection, mic level diagnostics, search, twenty-save history, offline
English speech recognition, MIDI editing and WAV transcription remain included.
V6.4/V6.5 lyric drafts stay in your user folder / IDW Audio Lab / Lyrics.
This package still contains Windows standalone and VST3, not AAX. Your Pro Tools
Intro connection continues through loopMIDI. No Pro Tools routing changes are
required for these companion-app improvements. Close Pro Tools and main IDW if
they prevent Audio Lab from opening your AudioBox for dictation.

## Tests and limits

41 Python tests include exact-command matching, disabled literal mode, punctuation,
Unicode, section boundaries, line joining and counter behavior. The packaged GUI
gate exercises command insertion and undo/redo plus search, meter and widget bounds.
Recorded-speech model tests do not establish recognition accuracy on your voice or
physical interface. Repeat a short dictation test on your PC.

Source checks: python -m unittest discover -s Tests -p 'test_*.py' -v
Build/package checks: scripts/build-windows.ps1 and scripts/package-audio-lab.ps1.
The Windows CI workflow also checks native regressions and VST3 pluginval.

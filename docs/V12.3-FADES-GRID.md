# V12.3 — clip fades, crossfades and beat snapping

This local source candidate adds nondestructive linear fades, overlap crossfades and a musical editing grid to Song Studio. Native Windows/macOS builds, installer validation, GUI inspection and AudioBox listening tests are still pending. These changes do not update your installed Windows app automatically.

## Smooth the beginning or end of a clip

1. Open **Song Studio > Timeline**, then select a clip by clicking its waveform or using the Clip menu.
2. Set **Fade in / s** and **Fade out / s**. For a short edge fade, try `0.01` seconds; for a gradual entrance, try `0.25` seconds. Adjust by listening.
3. Click **Apply clip / mix**. The waveform overview reflects the fade and aqua ramps show its duration.
4. Play the song or export the mix. Both use the same fade envelope. The original source audio remains intact.

Fade times refer to the selected clip's trimmed duration. Their combined length cannot exceed that duration. If you shorten a clip, reduce its fades if the edit is rejected. Zero disables a fade. Track gain, pan, mute and solo still affect all clips on the track.

Splitting in a clip's unfaded middle keeps the outer fade-in and fade-out, preserving combined playback. Splitting inside an existing fade is rejected. Disable or shorten that fade first if a cut there is necessary. Copying a clip copies its fades; moving a clip moves its fades with it.

## Blend two overlapping clips

1. Put two clips on the same track. Position the second so it starts before the first ends and extends to or past the first clip's end.
2. Select the first clip and press **Crossfade next**.
3. IDW finds the next clip by start time and applies a linear fade-out/fade-in over their overlap. This action is immediate and undoable; no Apply step is needed.
4. Listen, then **Save song**. If needed, Undo the crossfade or adjust the fade durations and Apply.

Example: clip A starts at `0` and lasts one second. Clip B starts at `0.75` and lasts one second. Crossfade next sets A's fade-out and B's fade-in to `0.25` seconds. The clips stay in place.

The command does not create overlap or extend source audio. It rejects gaps, equal-start pairs, and a next clip fully contained inside the selected clip. With several later clips, it uses the earliest start; ties use insertion order. Other overlapping clips still contribute to the mix.

This is a **linear** crossfade, not an equal-power mode. Matching signals maintain their level; different or out-of-phase signals may still sound louder or quieter. Listen before exporting. The command may shorten the first clip's fade-in or the second clip's fade-out so all fades fit their clips. Those changes are included in Undo.

Crossfade next sets ordinary clip fades; it does not link the clips. If you subsequently move or trim either clip, check the transition and reapply the crossfade if appropriate.

## Line up clips with the beat

Choose a grid in the new **Snap** menu:

| Setting | Spacing at 120 BPM |
| --- | --- |
| Off | Free positioning |
| Bar | 2 seconds, in the existing 4/4 meter |
| Beat | 0.5 seconds |
| 1/2 beat | 0.25 seconds |
| 1/4 beat | 0.125 seconds |

Snapping rounds to the nearest grid line starting at song time zero. It applies to the edit cursor, Split/Copy/Move at cursor, WAV import positions, and **Start / s** when you press Apply. A halfway position rounds forward. Source trim points and fade durations remain in seconds and are not snapped.

The grid follows the song BPM. It does not stretch audio, quantize performances or move existing clips when you change tempo. At the 180-second boundary, positions are clamped to the maximum. The grid display skips crowded lines at small window sizes; editing still uses the selected subdivision.

Snapping starts **Off** and lasts for the current editor session only. It is not saved in a song or preset. Playback still starts from bar 1; the aqua edit cursor does not seek playback.

## Save, recovery and compatibility

Songs with any nonzero fade use **format 5** and require V12.3. Formats 1–4 still load. Songs without fades retain earlier formats where possible. Save under a new filename if you want to keep an older-version copy.

Fade and crossfade edits support the existing bounded undo/redo history and stopped-song recovery. Sources remain shared between copies. Recording into an empty armed track begins with fades disabled; fades affect clip playback and export, not the incoming recorded samples. Save explicitly before closing.

This milestone does not add automatic fades to every cut, equal-power curves, waveform dragging, zoom, punch-in, time stretching or playback seeking. The four-track/64-clips-per-track and 180-second limits remain.

## Build and test

Use the project's existing Visual Studio 2022 C++/CMake prerequisites. From a developer terminal in the repository:

```bat
cmake -S . -B build-v12.3 -G "Visual Studio 17 2022" -A x64 -DBUILD_TESTING=ON
cmake --build build-v12.3 --config Release
ctest --test-dir build-v12.3 -C Release --output-on-failure
"build-v12.3\IDWVoiceMIDIStudio_artefacts\Release\Standalone\IDW Voice MIDI Studio.exe"
```

Configuration fetches pinned JUCE; an existing checkout can be supplied with `-DIDW_JUCE_PATH=...`. Audio Lab packaging remains separate. No V12.3 installer has yet been produced or validated.

`IDWSongFades` checks fade sample levels, splitting with outer fades, crossfade gain, undo/redo, format-5 persistence, malformed/truncated fade rejection, export parity, recovery snapshots and grid subdivisions/bounds. The existing clip, arrangement/arming, song, count-in and recovery tests run alongside it. Editor and processor code also receive a syntax check against the available JUCE source.

Before release, validate the native installer and plugin builds, inspect controls at minimum size in every skin, and listen through the AudioBox USB 96 when available. Check short edge fades, longer vocal entrances, crossfades between different takes, save/reopen, undo/recovery and exported audio.

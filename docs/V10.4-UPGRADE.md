# IDW Voice MIDI Studio V10.4 — Formant + Harmony Beta

V10.4 begins the advanced vocal-DSP phase while retaining the V10 tuner, V10.1 production rack, V10.2 Auto-Key and V10.3 adaptive engine.

## Added

- Optional **Formant Preserve (Beta)** based on LPC source-envelope transfer.
- Scale-aware audio harmony derived from the selected root and 12-note scale mask.
- Four harmony voicings: Upper 3rd, Low + High 3rd, 3rd + 5th and Octaves.
- Stereo placement and a dedicated Harmony Mix control.
- Updated natural vocal presets that enable Formant Preserve; Robot intentionally leaves it off.
- Native regression coverage for major/minor harmony intervals, scale stacks, octave stacks, formant-path bypass and long-run numerical stability.

## Safe evaluation

1. Use headphones and set a moderate AudioBox USB 96 input level.
2. Apply the correct key/scale or configure the scale strip manually.
3. Compare the same phrase with Formant Preserve off and on.
4. Enable Audio Harmony with Harmony Mix at 15%, then increase slowly.
5. Record dry vocals in Pro Tools Intro and keep the original track for comparison.

## Important limits

Formant Preserve is a beta implementation, not a guarantee of artifact-free extreme correction. The tuner and harmony detector remain monophonic. V10.4 does not include AAX, polyphonic vocal separation or voice cloning. Pro Tools Intro continues to use standalone + loopMIDI and Audio Lab WAV exchange.

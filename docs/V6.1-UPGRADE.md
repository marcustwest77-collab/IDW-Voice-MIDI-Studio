# IDW V6.1 — capture ideas and recall song scenes

## Save the idea you forgot to record

In Performance view, **Remember voice MIDI** is enabled by default. It retains up to 30 seconds of generated MIDI while audio is processing. Perform normally, then press **Save last 30s**. The snapshot freezes immediately, before the file dialog; later playing does not change that snapshot. Choose a .mid destination.

The snapshot includes lead, harmony, bass and beatbox MIDI generated by IDW. It does not record microphone audio or incoming keyboard MIDI. It does not change your current recorded take. Notes already held when the 30-second window begins are reconstructed with channel/controller context; notes and sustain are released at the end of the file.

The buffer follows audio-processing time, not elapsed wall time. If the DAW stops processing, the buffer stops advancing. Disabling Remember voice MIDI clears history on the next processed block; saving is immediately disabled. Unloading/restarting the processor loses the in-memory buffer. No disk file is created until you save.

Storage is bounded to 30,000 retained events and a 32,768-slot transfer queue. Exceptionally dense MIDI can shorten the effective window. If the message thread stalls long enough to overflow the queue, incomplete history is discarded and capture resumes with new events; a warning is shown on export. The gap warning remains until Remember voice MIDI is disabled and processed, or the processor is recreated. This is a creative recovery aid, not a crash-proof recorder.

## Save sounds for your verse, hook and bridge

1. Open **Studio instrument**.
2. Choose lead/chord/bass sounds, instrument level, brightness, attack, release and echo. Set your harmony/scale and beatbox settings in the other views as needed.
3. Type a scene name such as Verse, Hook or Bridge in the scene selector and press **Save scene**.
4. Choose a saved scene from the list to recall it. Held notes are released; sing or play the next phrase.

A scene stores instrument, harmony, key/scale, bend range, beatbox enable and drum-note assignments. It preserves microphone gate/confidence/input calibration, voice range, recording tempo, MPE configuration, MIDI learn mappings, drum training, retrospective preference and device selection. It does not store DAW synth patches or DAW routing. Scene recall is manual; it is not a sequencer or automatic song arrangement.

Scenes are XML files in the user application-data directory under `IDW Voice MIDI Studio/Song Scenes`. Saving the same name replaces that scene atomically. Invalid/missing/out-of-range fields cause the entire load to be rejected before settings change. Your DAW session stores recalled parameter values; the scene library remains separate local files.

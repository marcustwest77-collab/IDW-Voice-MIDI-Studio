# V6.5 — microphone diagnostics and lyric history

Run the bundled Run-Audio-Lab.cmd and open Lyrics / talk to text.

## New controls

- Find song searches saved titles and lyric contents, ignoring letter case.
- Mic channel selects Input 1 or Input 2 before dictation starts. Choose the socket used on your AudioBox or other interface. A mono device cannot provide Input 2; select Input 1 if the app reports that channel unavailable.
- The microphone meter displays RMS dBFS while dictating. Below -55 dBFS it suggests checking the microphone/gain; samples approaching full scale show a clipping warning. These are diagnostic hints, not an automatic gain control. Silence cannot distinguish a muted mic from a quiet room.
- MIC ON names the actual input device, selected channel and sample rate. On device errors, check the selected input, Windows microphone permission and other apps holding the interface.
- History previews up to 20 earlier saved revisions. Restore as new song creates a separate '(recovered)' draft without overwriting the original. A current unsaved draft must save successfully before recovery proceeds. History is saved on edits, including automatic saves every two seconds: it is limited revision history, not long-term backup. Export TXT for milestones.
- V6.4 drafts remain readable. Their previous-save copy is available as a fallback when no newer history exists.

Microphone audio stays local and is never saved by dictation. No account is required. Dictation remains English spoken-word recognition; edit recognition mistakes manually. Stop dictation before using another Audio Lab job. Input selection is currently per session.

## Your Pro Tools Intro setup

IDW remains a Windows standalone app and VST3; this update does not add AAX.
For live playing: start loopMIDI, then IDW, then Pro Tools Intro. Use the same
IDW to Pro Tools port as IDW's MIDI output and the record-armed Pro Tools instrument
track's input. Keep MIDI Thru on. For a simple melody use channel 1 with MPE off.
You confirmed live playing, recording and playback using V6.2; the newer packaged
build still needs a check with your physical AudioBox. Close Pro Tools and main IDW
when dictating if the interface cannot be shared.

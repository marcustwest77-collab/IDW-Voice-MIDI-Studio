# V12.2 — arrange songs with multiple clips

This local source candidate adds up to **64 clips per audio track** to the four-track studio. You can add separate WAV files, split a performance, repeat a hook and move an ad-lib without changing the source audio. It includes the V12.1 armed-track recording feature. It is not yet a validated Windows installer.

## Arrange your first song

1. Open **Song Studio**. Set BPM and Bars in Beat controls. At 120 BPM each bar is two seconds; eight bars is 16 seconds. Turn down Beat level if you are using an imported beat instead of the built-in drums.
2. Open **Timeline**, select **2 / Beat / backing**, set **Edit cursor / s** to `0`, then **Add WAV clip…**. Choose a mono/stereo WAV, 8–192 kHz, up to 180 seconds. Adding audio keeps existing clips.
3. Select **1 / Lead vocal**. Add a vocal WAV, or arm the empty track and record. Recording starts at bar 1 after any count-in. Use headphones; the existing tracks play without being recorded into the new performance.
4. Select the vocal clip by clicking its waveform or choosing its number from the **Clip** menu. The selected clip has a brighter outline. Where clips overlap, clicking selects the last drawn clip; the menu lets you reach every clip.
5. Place the aqua edit cursor inside the selected clip by clicking the timeline or typing seconds into **Edit cursor / s**. Press **Split at cursor**. This creates two source regions with unchanged combined playback. Splitting at the clip's endpoints is rejected.
6. To repeat a section, select it, set the edit cursor to the new start time, then **Copy to cursor**. The new copy is selected. To reposition it, change the cursor and use **Move to cursor**. These buttons act immediately and support Undo.
7. For detailed edits, adjust **Start / s**, **Trim in / s** and **Trim out / s**, then press **Apply clip / mix**. Start is a position in the song; trim values are positions inside that clip's original audio file. Trimming keeps the full source available.
8. **Track gain**, **Track pan**, **Track mute** and **Track solo** affect every clip on the selected track. Press **Apply clip / mix** after changing them. These controls are separate from any effects already baked into the audio.
9. Set Bars long enough for the arrangement and press **Play song**. The white line is the playback position; the aqua line is the edit cursor. Playback still starts at bar 1, regardless of the edit cursor.
10. **Save song** embeds the audio and edits. Use **Export mix WAV** for a 48 kHz / 24-bit stereo mix.

## What each edit changes

| Control | Result |
| --- | --- |
| Add WAV clip | Adds a new source at the edit cursor; keeps the track's existing clips and mix |
| Split at cursor | Cuts the selected region into two clips sharing the same audio |
| Copy to cursor | Adds a copy using the same source and trim range |
| Move to cursor | Changes only the selected clip's timeline start |
| Apply clip / mix | Applies the selected clip's timing and the whole track's mix controls |
| Remove clip | Removes only the selected clip, after confirmation |
| Clear armed track | Removes every clip on the armed track, after confirmation, in Beat controls |
| Undo / Redo track edit | Restores recent clip, import, mixer and recording edits |

Clips keep insertion order in the menu; moving them does not renumber them by time. Removing one renumbers the remaining clips. Tracks remain Lead, Beat/backing, Double and Ad-lib, but any track can hold any audio content.

## Recording and listening

Recording still requires an **empty armed track**. Selecting another waveform does not change the armed track: use **Arm selected lane**. Save existing work before clearing a track. This version does not record a new clip directly into an occupied track or provide punch-in, comping or simultaneous multichannel recording.

Overlapping clips are summed; overlaps can sound louder. Move or trim them apart if overlap is unintended. The existing output guard remains active. A muted track is silent; soloing a track suppresses other tracks and the synthesized beat. More than one track may be soloed. Track pan is stereo balance, not stereo-width processing.

There are no automatic fades or crossfades yet, so cuts can click at abrupt waveform changes. There is no beat snapping, waveform dragging, zoom, time stretching, cross-track clip movement or automation in this milestone. Numeric positioning and the edit cursor are the available arrangement controls. Changing tempo does not stretch audio.

The song remains limited to 180 seconds. Clips may be placed beyond the chosen Bars, but the part beyond the song end is excluded from playback/export. Increase Bars to hear it. Edits/imports require stopped transport.

## Saving, compatibility and recovery

- Multi-clip songs use **format 4** and require V12.2. Older song formats 1–3 still open. Songs without extra clips retain the earlier format where possible.
- Save an older project under a **new filename** before adding multiple clips if you want to retain a version that older installations can open.
- Copies and splits share immutable source buffers. Each source is embedded once per track in format 4, including when referenced by several clips. Independent imports remain independent sources.
- The existing 512 MiB audio/history budget and up-to-eight undo states remain. Loading, import and recovery can temporarily use more process memory. Undo history is not stored in the project.
- Stopped-song recovery snapshots include all clips and track settings. In-progress recordings still need to finish before audio can be checkpointed. Save song remains the permanent save.

## Build and run on Windows

Use Visual Studio 2022 with Desktop development with C++ and CMake, as in the existing project build instructions. From a developer terminal in the repository:

```bat
cmake -S . -B build-v12.2 -G "Visual Studio 17 2022" -A x64 -DBUILD_TESTING=ON
cmake --build build-v12.2 --config Release
ctest --test-dir build-v12.2 -C Release --output-on-failure
"build-v12.2\IDWVoiceMIDIStudio_artefacts\Release\Standalone\IDW Voice MIDI Studio.exe"
```

Configuration fetches the pinned JUCE source; an existing copy can be supplied through `-DIDW_JUCE_PATH=...`. Audio Lab packaging remains separate. The source changes do not automatically update the installed Windows app. No installer has been produced or validated for this local candidate.

## Validation

`IDWSongClips` covers split continuity, shared sources, independent WAVs, source-rate conversion, placement, overlapping playback, track mix, format-4 round trips, malformed source references, export parity, undo/redo, immutable recovery, occupied-track recording protection, clean armed capture, clip bounds and older-file migration. Existing arrangement/arming, song, count-in and recovery suites are also run. Editor and processor source receives a JUCE syntax check.

Before release, run the full native build/CTest and plugin validation workflow, inspect Timeline at minimum window size in every skin, and perform listening/latency tests with the AudioBox USB 96 when available. Test a split vocal, repeated hook, overlapping ad-libs, Save/Open, recovery and WAV export. These native GUI, installer and hardware checks are still pending.

# IDW Voice MIDI Studio V9.2

V9.2 focuses on first-run success and visible performance feedback.

## Added

- Modern gloss-panel interface with an IDW brand mark and low-overhead live microphone meter.
- Guided DAW Connection Center profiles for Pro Tools Intro/Windows, FL Studio, Ableton Live, REAPER, Logic Pro, generic VST3/AU hosts, standalone MIDI, and the built-in instrument.
- A dedicated Pro Tools Intro + AudioBox USB 96 flow that clearly explains why the VST3 does not appear in Pro Tools and how to use the standalone through virtual MIDI.
- Route-specific steps in the copied setup report for reproducible troubleshooting.
- Pure C++ regression coverage that locks the route IDs and verifies the Pro Tools, AudioBox, phantom-power and virtual-driver warnings remain present.

## Compatibility

- Windows: standalone and VST3.
- macOS: standalone, VST3 and Audio Unit.
- Pro Tools: standalone MIDI bridge. No AAX build is included.

Existing presets, scenes, voice profiles, lyrics, checkpoints and recorded MIDI remain compatible.

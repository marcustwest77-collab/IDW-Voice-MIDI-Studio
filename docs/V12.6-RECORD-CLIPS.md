# V12.6 — record new clips into existing tracks

This local source candidate adds **Record cursor** to Timeline. You can record another phrase, hook or ad-lib on a track that already has audio without deleting or replacing the existing clips. Native installers, GUI inspection and AudioBox USB 96 listening/latency tests remain pending.

## Record another phrase

1. Open **Song Studio** and set BPM and Bars long enough for the performance.
2. Open **Timeline**, select the intended track, then click **Arm selected lane**. Selecting a clip alone does not change the recording destination.
3. Place **Edit cursor / s** where the new phrase should begin. Snap applies if enabled. Zoom and View scrolling can help locate the phrase.
4. Choose the desired Count-in in the main transport: Off, one bar or two bars.
5. Use headphones and check your microphone input meter. **Record cursor / N** identifies the armed track by number. Press it to enable microphone monitoring and start.
6. The count-in plays first, with no captured audio. Then recording starts at the edit cursor. Existing clips and the beat play from that song position while IDW captures only its processed input into the new clip.
7. Press **Stop** when finished. Recording also stops at the song end. The clip appears on the armed track; select it from the Clip menu to trim, move or add fades.
8. **Save song** preserves all clips. **Undo track edit** removes the latest recording; Redo restores it within the existing history budget.

To record the next phrase, move the cursor and repeat. You can use any of the four tracks. If the armed track is empty, Record cursor creates its first clip at the chosen position.

## Existing audio and monitoring

Existing clips are kept, including clips on the armed track. They remain audible during the new performance according to track gain, pan, mute and solo settings. Their playback is excluded from the new recording internally. Use headphones so the microphone does not physically pick up the backing audio.

New clips contain the processed IDW input, so vocal effects/instrument sound generated before Song Studio are baked in as before. Track mixer settings affect monitoring/playback, not the captured sample levels. A muted track can still record input even though its monitoring is silent. Disable interface direct monitoring if hearing it together with software monitoring causes an echo.

Overlapping takes play together afterwards. Record cursor does not automatically mute, replace or select the best take. For a replacement phrase, keep a saved copy and explicitly trim/remove the old region, or use another track. Automatic punch replacement, take comping, loop recording and independent input monitoring per clip are not included.

## Protection and limits

- The main **Record lane** button retains its old behavior: bar-1 recording into an empty armed track. Occupied tracks direct you to Timeline > Record cursor.
- A cursor at or beyond song end, a full 64-clip track, unavailable audio rate or insufficient audio-memory budget rejects recording.
- Cancelling during count-in leaves no new clip and keeps all existing audio. The reserved capture buffer may remain until the next edit/play/record action. The existing undo system may retain a no-change entry for that cancelled attempt.
- Seek, track arming, clip edits and imports stay locked during recording/count-in. Section loops do not control recording; the new clip records once until Stop or song end.
- The song remains limited to 180 seconds. The new buffer is allocated only for the remaining duration from the cursor, before recording starts.
- Stopped-song recovery includes completed clips. In-progress recording remains unprotected; finish and Save song.

No new project format is introduced. New recordings use the existing clip formats, so V12.5 can reopen them. Files containing sections still require format-6 support; fades and multi-clip compatibility remain as previously documented. Record cursor is not an automatic update to your installed Windows app.

## Build and run on Windows

With the repository's Visual Studio 2022 C++ and CMake prerequisites, run from a developer terminal in the repository:

```bat
cmake -S . -B build-v12.6 -G "Visual Studio 17 2022" -A x64 -DBUILD_TESTING=ON
cmake --build build-v12.6 --config Release
ctest --test-dir build-v12.6 -C Release --output-on-failure
"build-v12.6\IDWVoiceMIDIStudio_artefacts\Release\Standalone\IDW Voice MIDI Studio.exe"
```

Configuration fetches pinned JUCE; use `-DIDW_JUCE_PATH=...` for an existing checkout. Audio Lab packaging is separate. No V12.6 installer has been validated yet.

## Validation

`IDWSongOverdub` covers all four destinations, preserved takes and recovery snapshots, same-track monitoring without backing capture, mono/stereo input, count-in cancellation, empty-track cursor recording, clip timing, undo/redo, project round trips, song-end stopping and the clip-count cap. Existing arrangement/arming, song, count-in and recovery tests also run. Editor/processor syntax is checked against available JUCE sources.

Release checks remain: native Windows/macOS builds, plugin and installer validation, minimum-size/all-skins Timeline inspection, and AudioBox listening. Test input latency, a second phrase over an existing vocal, Stop, cancelled count-in, Save/Open, Undo/Redo, export and return to ordinary bar-1 recording.

# V12.9 — separate tracks for DAW transfer

This local source candidate exports five aligned audio files, so you can continue mixing a song in another DAW. Native builds, installers, GUI inspection and real DAW listening remain pending.

## Export

1. Save your song and stop transport.
2. Review clip choices, track mute/solo, gain, pan, fades and master track/beat levels. Export prints those settings. Clear solo/mute if you want every track included audibly.
3. Choose **Export audio > Export separate track WAVs**.
4. Select a parent folder. IDW creates a new uniquely named `IDW-Stems-...` folder; it does not replace earlier exports.
5. Wait until the completion message appears. Export currently runs synchronously and the window may pause while it renders.
6. Open the folder and read `IMPORT-INSTRUCTIONS.txt` for the song's BPM and bar count.

| File | Contents |
|---|---|
| 01-Lead.wav | Lead track and its selected vocal phrases |
| 02-Backing.wav | Imported backing-track clips |
| 03-Double.wav | Double track |
| 04-Ad-lib.wav | Ad-lib track |
| 05-Drum-pattern.wav | Synthesized kick/snare/hat pattern |

Every file is 48 kHz, 24-bit stereo, starts at song time zero and has the full song duration, including initial silence. Empty/muted tracks still produce a silent file to keep the layout predictable. Loops, sections and the edit cursor do not shorten export. Audio beyond the configured song end is excluded.

## Bring the tracks into your DAW

Create a session at the BPM written in the instructions. Import all five WAVs onto separate stereo audio tracks, placing all files at exactly the same session-start position. Disable automatic stretching/tempo matching to preserve their timing. A 48 kHz session avoids sample-rate conversion; otherwise let your DAW convert all files consistently.

Begin with track faders at unity and centered stereo balance, since IDW's track gain and pan are already printed. Listen through the full arrangement and compare with **Export audio > Export full mix WAV**. Avoid playing the full mix alongside the stems, which would double the audio.

This transfers rendered audio, not editable MIDI, plugin settings or a native DAW session. It does not require an IDW plugin to be loaded in the receiving DAW. Vocals recorded through IDW effects already contain those effects; export cannot recover an unprocessed microphone take.

## Levels and protection

Current clip mute, track mute/solo, fades and gain/pan apply. Track solo also suppresses the drum pattern, matching playback. Count-in, metronome and live microphone are excluded.

Each file uses the existing output safety limiter. At ordinary levels the files sum to the full mix within PCM rounding. If limiting is active, independently limited stems may not sum exactly to the limited full mix; lower levels and audition the result. A stem sum can still overload the receiving DAW, so leave headroom.

Files are rendered into a temporary sibling directory, then moved to the final new folder after all files and instructions succeed. Handled failures attempt to remove the partial directory and report its location if cleanup fails. A crash or forced shutdown can leave an `IDW-export-...` partial folder; do not treat it as a completed export. Export does not change song data or the project format. Five maximum-length stereo files need approximately 260 MB of free disk space.

## Build and run on Windows

From a Visual Studio 2022 C++ developer terminal with CMake:

```bat
cmake -S . -B build-v12.9 -G "Visual Studio 17 2022" -A x64 -DBUILD_TESTING=ON
cmake --build build-v12.9 --config Release
ctest --test-dir build-v12.9 -C Release --output-on-failure
"build-v12.9\IDWVoiceMIDIStudio_artefacts\Release\Standalone\IDW Voice MIDI Studio.exe"
```

Configuration uses pinned JUCE or `-DIDW_JUCE_PATH=...` for a local checkout. Audio Lab packaging is separate. This source milestone does not update an installed copy.

## Validation

`IDWSongStems` checks file format and duration, initial silence, isolated track levels, fades/pan, muted alternatives, solo/drum suppression, low-level sum against full mix, deterministic drum timing, tempo notes and overwrite/transport protections. Clip and take regressions cover the shared renderer and export paths. Native export-menu inspection, maximum-duration/disk-failure checks and target-DAW listening remain release gates.

# IDW Voice MIDI Studio V10.5 — Release Polish

V10.5 turns the V10.4 DSP branch into a safer release candidate while keeping old sessions loadable and the audio engine local.

## New controls

- **Clip Guard** is a final soft peak stage with a -0.5 dBFS knee and sub-0 dBFS ceiling. It includes vocal, preview and Studio Instrument output and reports how many processing blocks required protection.
- **Harmony Gate** fades audio harmony voices in and out from pitch confidence instead of allowing uncertain frames to produce full-level harmonies.
- **CPU quality** offers Eco, Studio and High modes. Eco removes the LPC formant path and second harmony voice; High doubles LPC analysis frequency relative to Studio.
- **Safe Tracking** keeps tuning and core dynamics but bypasses formants, audio harmony, doubler, reverb and delay for a lower-risk recording cue.
- **A/B snapshots** temporarily store and recall two complete Vocal FX configurations.

## Presets and recovery

- Added Safe Tracking, Wide Pop Harmony, Low CPU Live and Modern Rap Lead factory presets.
- Every factory preset now resets the entire Vocal FX rack and V10.5 safety state before applying its own values, preventing settings from a previously loaded preset from leaking into the next one.
- User preset writes are atomic. Overwriting retains one previous XML copy, and loading falls back to it when the latest file cannot be parsed.

## Branding and packaging

- The official IDW Entertainment crown/wings/microphone logo is embedded in the editor, standalone splash, application icons and Windows installer.
- Windows and macOS package versions are synchronized at 10.5.0, and CI stages this upgrade guide.

## Compatibility and remaining release gates

- Existing V5–V10.4 states receive explicit V10.5 defaults: Studio quality, Safe Tracking off and Clip Guard on.
- Live transcription remains monophonic. Pro Tools Intro still uses the standalone application plus loopMIDI because this package does not include AAX.
- Formant Preserve remains Beta pending broader microphone/voice listening tests.
- Windows/macOS compilation, pluginval, AU validation, installers, hardware listening and Windows display-scaling checks run after the release-candidate branch is pushed with approval.

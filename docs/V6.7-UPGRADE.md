# V6.7 — named lyric checkpoints and text import

Extract the entire ZIP to a new folder. Open Run-Audio-Lab.cmd → Lyrics / talk to text.

## Save a milestone

Click Save checkpoint, enter a name such as Original hook or Before rewrite, and
confirm. IDW first saves the current draft, then writes a separate named snapshot.
If saving fails, your displayed lyrics remain and no success is reported.
Checkpoint names may contain punctuation and duplicate names are allowed; unique
IDs identify the files. Names are 1–80 characters.

Checkpoints previews versions of the current song. Choose a version and click
Restore as new song to create a recovered draft. The original song and checkpoint
remain unchanged. The current draft must save successfully before restoring.

Checkpoints stay beyond the rolling 20-save History. Up to 100 checkpoints are
allowed per song; at the limit, creating another is refused without deleting any.
There is no checkpoint-delete command in this version. Use Export TXT for extra
milestones. These copies live on the same disk, under your user folder / IDW Audio
Lab / Lyrics / checkpoints / song ID; they are not a backup against disk loss.
Back up the Lyrics folder or export important text to another location.
After an abnormal process termination, if a checkpoint lock persists: close all
Audio Lab windows before removing only that song's checkpoints/.write.lock file.
Do not remove locks while another Audio Lab window is saving.

## Import existing lyrics

Click Import TXT and choose a plain-text .txt file. UTF-8 (with or without BOM) and
UTF-16 with BOM are supported. Other encodings show an error rather than guessing.
Limits: 4 MiB and 1 million decoded characters. Binary/NUL-containing data is rejected.

The file's name becomes the new song title; its entire contents become the lyrics.
Windows/Mac line endings are normalized to newlines. A title already inside the
text is kept, not silently removed. Importing twice creates separate songs. The
source file is never modified. Invalid input leaves the current draft displayed.
Import saves your current draft first; if saving fails, import does not proceed.

Checkpoint creation, recovery and import are disabled while dictating. Stop
first so incoming words cannot go into another song.

## Verification and compatibility

47 Python tests cover existing behavior and import encodings, unchanged source
files, size/format rejection, checkpoint survival beyond rolling history, duplicate
labels, write failures and the 100-checkpoint limit. The packaged GUI test creates
a named checkpoint and imports a fixture through the actual UI callbacks, checks
the original draft remains intact, and reruns commands/undo/redo/search/layout.

Windows standalone and VST3 are included; this is not an AAX build. Your Pro Tools
Intro connection remains IDW standalone → loopMIDI → instrument track. AudioBox
Input 1/2, microphone meter, spoken commands, counts and MIDI editor remain available.
Physical microphone accuracy still needs a live check on your PC.

Source tests: python -m unittest discover -s Tests -p 'test_*.py' -v
Windows build: scripts/build-windows.ps1
Packaged Audio Lab checks: scripts/package-audio-lab.ps1

The Audio Lab window now sizes itself to the screen on launch. WAV selection
controls are hidden in the Lyrics and MIDI editor tabs to leave more editing room.
The save status and log area retain space at smaller window sizes.

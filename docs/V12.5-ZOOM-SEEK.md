# V12.5 — timeline zoom and playback seeking

This local source candidate adds a closer timeline view and explicit playback navigation. It does not yet provide a validated Windows installer. Native GUI inspection, large-project responsiveness and AudioBox listening/latency checks remain release gates.

## Inspect a phrase

1. Open **Song Studio > Timeline** and click near the phrase you want to inspect, or enter its position in **Edit cursor / s**.
2. Press **Zoom +**. Each press doubles the zoom: 1×, 2×, 4×, 8×, 16×, 32×. The visible window centers around the edit cursor where song boundaries allow.
3. Use **View / s** to scroll horizontally. Its value is the time at the left edge of the waveform area. The timeline header shows the visible start and end times.
4. Press **Zoom −** to widen the view or **Fit song** to show the complete song again.

Zoom and scrolling do not change clips, fades, sections, tempo or audio. Grid lines, clip selection, fade ramps and section markers use the visible time window. Clicking within a zoomed view still selects the correct absolute song time, then applies your Snap setting.

Zoomed waveforms use source samples from the visible interval for a more detailed overview. They are sampled peak displays, not a sample editor or a loudness meter. The clip count label is hidden when a track row is too short; the clip menu remains available. Closely spaced section labels can also be omitted; the Sections menu retains their exact names and bar ranges.

The view does not automatically follow playback. If the cursor or playhead moves offscreen, scroll or Fit song to see it. Zoom/scroll are editor-session settings and are not saved to the song or undo history.

## Start listening from the edit cursor

1. Stop transport.
2. Click a timeline position or type **Edit cursor / s**. If Snap is enabled, it uses that musical grid.
3. Press **Play cursor**. Playback begins there and continues to the song end.
4. Use the main **Stop** button when finished.

The cursor must be before the song end. **Play song** still starts at bar 1. Merely clicking a clip does not start or move playback.

## Jump during playback

1. Start Play song, Play cursor, Play section or Loop section.
2. Set the edit cursor to the desired destination.
3. Press **Seek cursor**.

For normal song playback, the destination can be anywhere inside the song, including before the original Play cursor start. For section playback—one-shot or looped—the destination must stay inside that section. A loop continues to wrap at the same boundaries after seeking.

To jump outside a section, Stop and use Play cursor or start another section. An invalid seek leaves playback at its current position. The section/song end itself is excluded because no audio remains to play there.

Seeking resets the built-in drum and metronome state at the destination. It does not reconstruct the tails of earlier drum hits or apply a smoothing crossfade at the jump. Abrupt seeks through sustained audio may click; this feature is for navigation and rehearsal, not rendered transition editing.

## Recording, saving and export

- Seek cursor is disabled during recording and its count-in, and the engine rejects those requests too.
- Recording retains the existing bar-1 start, count-in, empty-armed-track requirement and overwrite protection.
- Seeking changes transport position only; it does not edit source audio, create an undo step or mark the project audio as changed.
- WAV export still renders the full song once, regardless of the view, last seek or playback start.
- This milestone introduces no new project format. V12.4 can still open format-6 songs saved by V12.5; earlier-format compatibility remains as documented in prior guides.

## Build and run on Windows

Use the existing Visual Studio 2022 C++ and CMake prerequisites. From a developer terminal at the repository root:

```bat
cmake -S . -B build-v12.5 -G "Visual Studio 17 2022" -A x64 -DBUILD_TESTING=ON
cmake --build build-v12.5 --config Release
ctest --test-dir build-v12.5 -C Release --output-on-failure
"build-v12.5\IDWVoiceMIDIStudio_artefacts\Release\Standalone\IDW Voice MIDI Studio.exe"
```

Configuration fetches pinned JUCE; an existing checkout can be supplied with `-DIDW_JUCE_PATH=...`. Audio Lab packaging is separate. The source changes do not update your installed Windows app automatically; no V12.5 installer has yet been validated.

## Validation

`IDWSongSeek` checks zoom/scroll coordinate conversion, cursor anchoring, view bounds, Fit song, cursor playback sample positions, backward seeking, rejected seeks, stopping at song end, section/loop bounds, loop wrapping after a seek, recording/count-in protection and deterministic rhythm reset. Existing section, count-in and song tests also run. Editor/processor syntax is checked against available JUCE sources.

Before release, run the native builds and plugin/installer validation. Inspect Timeline in every skin at minimum window size; zoom/scroll near both song boundaries; verify waveform and fade alignment, overlapping clip selection, section markers and Snap. Test responsiveness with many overlapping clips. With the AudioBox USB 96, listen to repeated forward/backward seeks, looped-section seeks, Stop and normal recording afterwards.

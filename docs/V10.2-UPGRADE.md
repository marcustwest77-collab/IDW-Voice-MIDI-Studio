# IDW Voice MIDI Studio V10.2 — Auto-Key Assistant

V10.2 adds a local key-learning workflow around the existing AutoTune-style pitch correction and V10.1 vocal production rack.

## Added

- **Learn key** captures pitch-class evidence from the same validated live vocal detector used by voice-to-MIDI.
- Major/minor scoring across all 24 common keys.
- Root, mode and confidence readout directly inside Vocal FX.
- **Apply key** sets the tuning root, major/minor scale mask and Song scale mode in one action.
- Lock-free audio-thread collection; no files, microphone recordings, network requests or cloud processing.
- A dedicated native test for major detection, minor detection, minimum evidence and start/stop behavior.

## Recommended use

1. Calibrate noise and confirm the pitch display follows your voice.
2. Open Vocal FX and click Learn key.
3. Sing a clear verse or hook for 10–20 seconds with little background bleed.
4. Click Stop learning and inspect the suggestion.
5. Click Apply key only when it matches the song, then choose a tuning preset.

Auto-Key is an assistant, not an infallible music-theory engine. Relative major/minor songs use the same notes, so tonal emphasis matters. The user always confirms the result before tuning settings change.

# IDW Voice MIDI Studio V10.1 — Vocal Production Rack

V10.1 builds on the verified V10 tuner without changing the working voice-to-MIDI engine, Audio Lab, lyrics workspace, Tune Studio, or Pro Tools Intro workflow.

## Added

- A live, local vocal production rack after the pitch-correction stage.
- Individually bypassable De-Esser, Compressor, Saturation, Doubler, Reverb and Delay modules.
- A master Rack Mix control for parallel dry/wet blending.
- Stereo width from different short doubler taps while keeping the input and pitch detector mono-compatible.
- Updated Natural, Smooth R&B, Tight, Memphis Hard, Singing Rap and Robot presets that configure both tuning and vocal effects.
- Backward-safe parameter migration: the complete rack defaults off in V10 and older sessions.
- A dedicated DSP regression test for true bypass, dry mix, finite/bounded output and stereo generation.

## Safe starting workflow

1. Connect headphones to the AudioBox USB 96 and close any app that is holding its ASIO driver.
2. Open the IDW standalone app, choose the AudioBox ASIO device and the microphone's actual input.
3. Calibrate noise while quiet, then open Vocal FX.
4. Choose Natural and lower the AudioBox input gain if the meter clips.
5. Disable Delay and Reverb while recording a dry vocal you plan to edit later.
6. For Pro Tools Intro, continue using standalone + loopMIDI for MIDI and Audio Lab Tune Studio for corrected WAV import. Pro Tools Intro does not load the included VST3.

## Limits

- The live tuner remains monophonic.
- V10.1 does not add AAX or formant preservation.
- Delay time is fixed at 375 ms in this first rack release; automation-ready timing controls are planned for a later revision.
- The rack is an original IDW implementation and is not a copy of Voloco, Auto-Tune, or another commercial product.

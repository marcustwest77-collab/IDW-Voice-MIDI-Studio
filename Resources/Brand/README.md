# IDW brand assets

`IDWLogoOriginal.png` is the full-resolution IDW Entertainment artwork supplied by the project owner. It is preserved without visual alteration.

The other files are deterministic size/format derivatives for the application:

- `IDWLogoFull.png`: startup splash and large application icon.
- `IDWLogoIcon.png`: compact in-app and small application icon.
- `IDWVoiceMIDIStudio.ico`: multi-resolution Windows installer icon.
- `InstallerSidebar.bmp` and `InstallerSmall.bmp`: Inno Setup artwork.

Do not substitute or regenerate the lettering, crown, wings, diamonds, microphone or `Ent` script. Resize from the original while preserving its aspect ratio.

# IDW V7 Production UI Direction
- Black gloss / brushed-black panels
- Gold trim and meter accents
- Large central pitch/note display
- 12-key scale strip
- Performance modules: Voice, Drums, Expression, MPE, MIDI Learn
- Preset bar across top
- IDW Ent. logo slot centered above main readout
- Avoid excessive animation; prioritize low GPU/CPU overhead in DAWs

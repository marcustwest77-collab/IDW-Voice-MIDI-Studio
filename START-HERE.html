IDW Voice MIDI Studio V9.2

First sound

  1. Open IDW Voice MIDI Studio.
  2. Choose your interface in Options > Audio/MIDI Settings.
  3. Open Setup / Help and select your DAW.
  4. Enable the IDW instrument and press Send test note.
  5. Stay quiet and calibrate noise, then sing one steady note.

What is new

V9.2 adds a modern performance interface, a visible live mic meter, and a guided DAW Connection Center. Profiles cover Pro Tools Intro on Windows, FL Studio, Ableton Live, REAPER, Logic Pro, generic VST3/AU hosts, standalone MIDI and the built-in instrument. Copied setup reports now include the selected route instructions.

Pro Tools Intro + AudioBox USB 96

Pro Tools does not load the included VST3. Run IDW as a standalone application and send MIDI through a virtual port such as loopMIDI. In IDW choose the AudioBox input/output and virtual MIDI output. In Pro Tools enable that port, select it on a record-armed Instrument track, and load an instrument. Use the Pro Tools profile inside Setup / Help, then send the test note.

Audio Lab

Open IDW Audio Lab for offline lyric dictation, lyric checkpoints/import/export, MIDI take editing, and recorded WAV-to-MIDI transcription. The optional cloud voice-conversion feature is the only Audio Lab path that sends media off the computer and requires an existing account.

IDW Voice MIDI Studio V10 — Vocal FX Edition

First sound

  1. Open IDW Voice MIDI Studio.
  2. Choose your interface in Options > Audio/MIDI Settings.
  3. Open Setup / Help and select your DAW.
  4. Enable the IDW instrument and press Send test note.
  5. Stay quiet and calibrate noise, then sing one steady note.

What is new

V10 adds real-time monophonic Vocal Tune with chromatic/song-scale targets, six starting presets and detailed strength, speed, humanize, mix and output controls. Audio Lab now includes a local Tune Studio that creates corrected WAV copies for Pro Tools Intro.

Pro Tools Intro + AudioBox USB 96

Pro Tools does not load the included VST3. Run IDW as a standalone application and send MIDI through a virtual port such as loopMIDI. In IDW choose the AudioBox input/output and virtual MIDI output. In Pro Tools enable that port, select it on a record-armed Instrument track, and load an instrument. Use the Pro Tools profile inside Setup / Help, then send the test note.

Complete Pro Tools and AudioBox checklist

Vocal FX

Use headphones, open Vocal FX, enable Vocal Tune and begin with Natural. Song-scale mode follows the root and scale notes selected in Studio controls. Fast retune settings are a deliberate hard-tune effect.

Audio Lab

For Pro Tools Intro, export a dry 16-bit PCM vocal WAV, process a copy in Audio Lab > Tune Studio, then import the corrected WAV on a new track at the same timeline start. Local tuning does not upload audio. Audio Lab also provides lyric dictation, MIDI editing and WAV-to-MIDI transcription.

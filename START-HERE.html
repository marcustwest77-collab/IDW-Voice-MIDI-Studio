Run and test

  1. For the native program, use BUILD-WINDOWS.cmd with Visual Studio 2022 C++ tools, Git and CMake. After successful build/test, extract the generated portable ZIP and open Run-IDW.cmd.
  2. Open Studio instrument, enable the built-in instrument, then Test note. Choose sounds separately for lead, chords and bass.
  3. For Audio Lab, install Python 3.10 with Tkinter and the Python launcher, then open Companion/Run-Audio-Lab.cmd. Setup-Transcription.cmd installs the optional local model.
  4. Read complete V6 setup, feature boundaries and validation. The earlier illustrated microphone and VST routing guide remains available; its preview-only limitation describes V5.

Cloud processing is optional, requires your account, and asks before each upload. No user recordings were uploaded during development.

The experience we are building

Sing a melody → generate harmony and bass → hear the built-in instruments → record editable MIDI. Import recorded chords through Audio Lab when file transcription is needed. Connect to FL Studio when you want its instruments and arrangement tools.

Upcoming directions: retrospective capture, editable verse/hook/bridge scenes, personalized vocal gestures and highlighted uncertain notes. These are planned, not implemented in this candidate.

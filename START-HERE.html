IDW Voice MIDI Studio V6.7

Open the program

  1. Extract the entire ZIP into a new folder.
  2. Open Run-IDW.cmd for voice-to-MIDI, or Run-Audio-Lab.cmd for lyrics and transcription.
  3. Keep the Audio-Lab folder intact. Its runtime and offline speech/music models are included.

New in V6.7: named checkpoints and text import

Save checkpoint gives the current lyrics a name such as Original hook. Checkpoints previews these versions and restores one as a separate song. They stay beyond the rolling 20-save history; up to 100 per song, with no automatic deletion. These are local copies, so also export important lyrics to another location.

Import TXT creates a new song from a UTF-8 or BOM-marked UTF-16 text file. The filename becomes the title and the entire text becomes the lyrics. Existing songs and the source file are preserved.

Spoken songwriting controls

Enable Voice commands before dictation, then pause and say a command on its own: comma, period, question mark, new line, new paragraph, or section hook. Command help lists every supported phrase. Commands are off by default so those words can be ordinary lyrics. Uncheck New line per phrase to keep recognized phrases together. Undo and Redo apply to dictation edits. Word and nonempty lyric-line counts exclude bracketed section headings.

Lyrics and talk-to-text

  1. Open Audio Lab → Lyrics / talk to text. Type a song title.
  2. Refresh mics, select your AudioBox (or other microphone), and choose the input socket: Input 1 or Input 2.
  3. Click Start dictation and wait for MIC ON. Watch the input level. If clipping appears, lower interface gain. If quiet, check the cable, selected channel and gain.
  4. Speak your lines, then Stop. Correct recognized words manually. Drafts save automatically every two seconds; Save now saves immediately.
  5. Find song searches saved lyrics and titles. History previews up to 20 earlier saves; Restore as new song keeps the original. Export TXT makes a separate text copy.

Use headphones. If the mic is unavailable, close Pro Tools and main IDW, check Windows microphone permissions, then retry. Dictation uses local English recognition and does not save or upload microphone audio. It is intended for speech, not vocals over a backing track.

Voice-to-MIDI on its own

In IDW open Options → Audio/MIDI Settings, choose your interface input and headphone output. Start at 48 kHz and 256 samples if supported. Open Setup / Help, enable IDW's built-in instrument, then Send test note. Once audible, choose the correct microphone channel, calibrate noise while quiet and sing. Start with Melody on and MPE off.

Pro Tools Intro on Windows

This is a standalone application and VST3, not an AAX plug-in. Do not try to load IDW as a Pro Tools insert.

  1. Open loopMIDI with your existing IDW to Pro Tools port, then IDW, then Pro Tools.
  2. In IDW's Audio/MIDI settings, select that MIDI output port.
  3. In Pro Tools, enable that port under Setup → MIDI → MIDI Input Devices. Enable Options → MIDI Thru.
  4. Load your virtual instrument on an Instrument track. Select IDW to Pro Tools / channel 1 as MIDI input, and record-arm the track.
  5. Mute IDW's built-in sound and Preview. Send test note in IDW, then sing. Record in Pro Tools to save editable MIDI.

If IDW's mic stops when Pro Tools opens, resolve interface driver sharing first. The test note verifies MIDI routing but does not prove that the mic is working. Alternatively record/export MIDI in IDW, close it, then import the file into Pro Tools.

Other features

MIDI take editor opens a .mid file or Review latest MIDI from transcription. Click notes to edit pitch, velocity, timing and duration; Export copy writes a new file. Local transcription converts a PCM WAV to MIDI. The instrument, scenes, retrospective MIDI capture and optional cloud conversion remain available.
